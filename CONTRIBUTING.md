# Contributing

Use [the reproduction guide](docs/reproduce.md) to set up a local environment and run pytest. Keep fixture experiments bounded and write new outputs to an ignored directory. Include the exact configuration, engine version, seeds, data provenance and unsuccessful attempts when reporting experimental changes.

Treat archived code and evidence as research records. Put engine fixes and new experimental methods under `orbit_wars_research/framework/`. Correct a mistaken description in documentation or add a traceable evidence projection. Preserve original observations and their fingerprints.

Add focused regression tests for changes to game outcomes, decision gates, data splits or metrics. Include a short note on platform and environment coverage. Before proposing an external agent or data asset, identify its precise source and applicable redistribution terms. Keep raw replays, models, local registries and submissions separate from any release.

Original project-owned contributions are licensed under [MIT](LICENSE). Keep upstream rights and license notices separate. See the [provenance record](PROVENANCE.md) for the scope.
