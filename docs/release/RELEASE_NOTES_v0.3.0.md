# Orbit Wars v0.3.0 — Reusable research framework

This release pairs the exact 80-page V5 retrospective with an installable framework for designing, evaluating and extending Orbit Wars agents. V5 records a competition finish of 611 / 4,729 teams (Top 12.92%).

- Reuse bounded tournament, local agent registration, mutation, hybrid routing, evolutionary search, replay extraction, training, inference and staged validation commands.
- Inspect 5,800 individual OrbitLab attempts, the separate 52-candidate / 253-attempt evolutionary journal, Beast Lab stage and replay statistics, and 131 archived V14 checkpoints using four notebooks.
- Compare historical implementations with post-competition fixes for terminal statuses, applied seeds, replay-grouped splits and tied-score AUC.
- Read the V5 report with a separate retrospective. Review conceptual architecture and historical plots with linked provenance.
- Use MIT for original project contributions. External agents, code and datasets remain under their respective terms.

The release test report covers Windows x64 and Python 3.13. The Windows/Linux CI definition is included. The exact final Kaggle binary, original V14 corpus, historical Holdout score and evidence of a positive strategic effect from the exported V14 ranker remain unresolved.
